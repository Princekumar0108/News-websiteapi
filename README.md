# News-websiteapi
A responsive news website that fetches real-time headlines using News API. Built with HTML, CSS, and JavaScript, it features category-based filtering, keyword search, and dynamic content updates. Ideal for users seeking the latest global and local news in a clean, user-friendly interface.

# 📰 News Website API Project

A responsive news website built with **HTML**, **CSS**, and **JavaScript**, powered by the [NewsAPI.org](https://newsapi.org) to deliver real-time global headlines. Users can browse top stories, filter by category, and search for specific topics—all in a clean, user-friendly interface.

## 🚀 Features

- 🌍 Live news updates from trusted sources
- 🔍 Keyword-based search functionality
- 🗂️ Category filtering (e.g., Technology, Sports, Health)
- 📱 Responsive design for all devices
- ⚡ Fast and lightweight frontend

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **API**: NewsAPI.org
- **Deployment**: GitHub Pages / Localhost
